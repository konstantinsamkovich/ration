# Рацион

Дневник КБЖУ для iPhone и Windows. Для локального запуска откройте `index.html` в браузере. Сборка и зависимости не нужны.

Кнопка «Добавить» открывает форму продукта. Введите вес порции и КБЖУ на 100 г. Приложение покажет расчёт до сохранения. Нажмите на сохранённый продукт, чтобы изменить или удалить его.

В «Целях» можно задать минимум и максимум для каждого показателя. Пустой максимум означает цель «от». История показывает средние КБЖУ по дням с продуктами.

## GitHub Pages

Загрузите файлы в корень репозитория. В настройках репозитория откройте **Settings → Pages → Deploy from a branch**, выберите нужную ветку и **/(root)**. После публикации откройте адрес из раздела Pages.

На iPhone откройте этот адрес в Safari и выберите **Поделиться → На экран «Домой»**. На Windows откройте тот же адрес в браузере. После первой загрузки по HTTPS приложение кэширует файлы для работы офлайн.

Записи сохраняются локально в браузере. У каждого устройства своя история. Локальная копия и опубликованный сайт также используют разные хранилища.
